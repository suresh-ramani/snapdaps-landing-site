# Session context

Working context for Claude Code sessions on this repo, kept in git so it moves with the code to any
computer. CLAUDE.md says **what the code is and the rules**; these files say **how we work, what the
owner decided and why, and what's still open**.

Read at the start of a session:

| File | What's in it |
|---|---|
| [working-agreements.md](working-agreements.md) | How the owner wants work done: commits, docs, verification |
| [decisions.md](decisions.md) | Product / UX decisions the owner made, with the reason |
| [status.md](status.md) | Where things stand: recent work, open items, what's waiting on the team |
| [testing.md](testing.md) | How to check UI live in this setup, and known environment quirks |

Keep them current: when a session makes a decision, finishes or opens a task, or learns a quirk,
update the matching file in the same change (like CLAUDE.md). Write dates as YYYY-MM-DD.

**This repo is public.** Never put secrets, passwords, API keys, env values, personal emails or
phone numbers that aren't already on the site, or private customer data in these files.
